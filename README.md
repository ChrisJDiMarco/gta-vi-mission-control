# GTA VI Mission Control

Unofficial local Electron app for tracking legal money experiments around the GTA VI attention wave.

Unofficial fan project. Not affiliated with or endorsed by Rockstar Games or Take-Two Interactive. Grand Theft Auto and GTA are trademarks of Take-Two Interactive Software.

## Operating plan

Read `AUTONOMOUS_REVENUE_PRD.md` before using this app for any outbound or revenue work. The app is a local control surface. JARVIS can research, draft, score, and track opportunities autonomously, but Chris approves external messages, publishing, spending, account creation, affiliate links, and payment handling.

## Run

```bash
npm install
npm run icon
npm run pack
cp -R "dist/mac-arm64/GTA VI Mission Control.app" /Applications/
```

The app stores opportunities and tasks in localStorage. No backend, no keys, no official Rockstar assets.
